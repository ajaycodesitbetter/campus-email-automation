🎯 Goal: Add “Chat-style” Sections for Multiple Email Campaigns
Think of it like this:

Each section = 1 campaign thread (e.g., Placement Drive, Admission Notice, Event Invite)

You can create new sections (campaigns) dynamically

Each section has:

Its own email data

Its own subject/message

Its own email stats (sent/failed)

Then below all that, you keep your Summary Dashboard, Logs, and Actions.

import streamlit as st

tabs = list(st.session_state.campaigns.keys()) + ["➕ New Campaign"]
selected_tab = st.sidebar.radio("📂 Campaign Sections", tabs)

if selected_tab == "➕ New Campaign":
    new_name = st.text_input("Enter new campaign name")
    if st.button("Create Campaign"):
        if new_name and new_name not in st.session_state.campaigns:
            st.session_state.campaigns[new_name] = {}
            st.success(f"Created campaign: {new_name}")
            st.experimental_rerun()
else:
    st.header(f"📧 Campaign: {selected_tab}")
    # Use selected_tab to load the CSV, message, etc.

with st.form(f"Upload_{selected_tab}"):
    uploaded = st.file_uploader("Upload CSV", key=selected_tab)
    subject = st.text_input("Subject", f"Important Info for {{Section}}")
    body = st.text_area("Message Body", "Dear {{Name}}, ...")
    if st.form_submit_button("Save & Preview"):
        # Save data to that campaign
        st.session_state.campaigns[selected_tab]["csv"] = uploaded
        st.session_state.campaigns[selected_tab]["subject"] = subject
        st.session_state.campaigns[selected_tab]["body"] = body
